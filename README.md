# TourismCore

BIT API — vertical de negocio Turismo exclusivamente (workflows turísticos, perfiles turísticos, reglas propias del negocio, orquestación de PIMA para procesos turísticos).

Parte de la migración arquitectónica BIT → **Platform** ([PIMAPlatform](https://github.com/IIrola/PIMAPlatform)) / **PIMA** ([PIMACore](https://github.com/IIrola/PIMACore)) / **BIT** (este repo).

El código legacy de referencia (READ-ONLY, no se migra ni se toca) vive en el repo [BitCore](https://github.com/IIrola/bit-core).

Ver [.claude/CLAUDE.md](.claude/CLAUDE.md) y [.claude/MIGRATION_RULES.md](.claude/MIGRATION_RULES.md) para las reglas invariantes de la migración.
